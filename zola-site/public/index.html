VECTOMANCY

A blazing fast Rust and WebAssembly tool to convert raster images into mathematical parametric equations, Fourier series vectors, and Zhang-Suen thinned SVGs.

Launch Playground GitHub

Features

  • 100% Client-Side (No backend required)
  • Powered by WebAssembly for near-native performance
  • Multiple vectorization modes: Splines, Fourier Epicycles, Chaikin Polylines
  • Export directly to PNG, JPG, and JSON AST
