Vectomancy Pro Guide

Algorithms:
- Spline: Precise Bezier curves. Best for lineart and logos.
- Fourier: Continuous epicycle loops. Chaotic single-wire aesthetic.
- Chaikin: Smooth polylines using corner-cutting. Organic "hand-drawn" look.

Parameters:
- Detail: 10-100. Lower = abstract/fast, Higher = precise/heavy.
- Min Path: Filters out noise and artifacts. Clean = 5, Noisy = 15+.
- Terms/Iters: Controls complexity of Fourier/Chaikin modes.

Pro Tips:
- Clipboard: You can paste (Ctrl+V) images directly anywhere!
- Focus Mode (F): Hides UI for pure viewing.
- Transparent: Toggle in settings. Disables JPG export.
- Hotkeys: Use mouse wheel to zoom, drag to pan.
