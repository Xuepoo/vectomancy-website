VIDEO ENGINE

Frame-by-frame parametric decomposition.
Each frame converted to mathematical curves.
Now available in CLI v6.0.0

Available Features

  • Frame-by-frame Bezier spline extraction
  • Fourier epicycle animation export
  • Chaikin corner-cutting smoothing
  • MP4 / WebM / MKV / AVI / MOV / GIF output
  • Original audio preservation (AAC)
  • Transparent background (WebM + VP9)
  • GPU acceleration via wgpu
  • Multi-threaded CPU processing

Performance (GPU Mode)

480p Video (30fps)

~89 fps processing speed

1080p Video (30fps)

~8 fps processing speed

Quick Start

# Install (via cargo)
cargo install vectomancy-cli

# Convert video with audio
vectomancy video input.mp4 -o output.mp4

# Fourier mode
vectomancy video input.mp4 -o output.mp4  # set mode="fourier" in config

# Transparent WebM
vectomancy video input.mp4 -o output.webm  # set bg_transparent=true
