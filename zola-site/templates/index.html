Recent Updates

[v6.2.0] - 2026-06-25
  • Adaptive Fourier Compression: Dynamically selects the minimal number of Fourier terms to retain based on cumulative energy threshold (99.5% default) to accelerate equations.
  • Parameters & Defaults: Configurable via --fourier-adaptive / --fourier-energy CLI options, or fourier_adaptive in config.toml.
[v6.1.0] - 2026-06-24
  • AST Quantization: Truncates coordinates/expressions to 4 decimal places, saving ~40% file size and boosting rendering performance.
  • Zero Term Elimination: Automatically omits null coefficients in Desmos export equations.
  • Simplify Settings: New toggle checkbox added to Web UI Settings panel.
